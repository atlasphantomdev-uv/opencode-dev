## Packages needing special handling

Root `package.json` patches these exact AI SDK versions:

- `@ai-sdk/google@3.0.73`
- `@ai-sdk/groq@3.0.31`
- `@ai-sdk/mistral@3.0.51`
- `@ai-sdk/openai-compatible@2.0.41`
- `@ai-sdk/xai@3.0.102`

Patch behavior changes provider output/types: Google empty-content removal; Groq, Mistral, and xAI arbitrary `reasoningEffort`; OpenAI-compatible raw error propagation. Do not edit version keys alone. Rebase each patch against target package, then run provider tests and typecheck.

## Explicitly excluded

Latest registry versions are AI SDK 7 / provider-major 4 or 5 for most packages. Those upgrades are excluded by request. Examples: `ai 7.0.97`, `@ai-sdk/openai 4.0.65`, `@ai-sdk/provider 4.0.13`, `@openrouter/ai-sdk-provider 3.0.0`, and `ai-gateway-provider 4.0.0`.
