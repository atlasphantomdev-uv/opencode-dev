## Remaining gaps

- V2 MCP requires a location-scoped adapter and layer owner. Core cannot import `packages/opencode` MCP runtime; server cannot import opencode (`packages/server/package.json:14-18`).
- V2 diagnostics requires a producer/observation seam without moving LSP lifecycle into Core. Current V2 location graph has no LSP service.
- Configured local/remote instruction sources remain a separate V2 design slice.
